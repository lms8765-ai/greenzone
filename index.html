☁️ 클라우드 동기화란?
GitHub에 데이터를 저장하여 PC·태블릿·스마트폰 어디서든 같은 데이터를 사용할 수 있습니다.
PC에서 저장하면 30초 내에 모든 기기에 자동 반영됩니다.
📋 GitHub Personal Access Token 발급 방법
① github.com/settings/tokens/new 접속
② Note: greenzone-app 입력
③ Expiration: No expiration 선택
④ Select scopes: repo 체크 ✅
⑤ Generate token 클릭 → 토큰 복사 (ghp_로 시작하는 문자열)
🔗 새 토큰 발급 (repo 권한 자동선택)
💡 repo 권한이 반드시 필요합니다. 위 링크는 repo 권한이 자동 선택됩니다.
만료기간은 No expiration 권장. 발급 후 토큰을 복사해 붙여넣으세요.
